# Sameer Khan [2014] Landing Page

A responsive Bengali landing page inspired by the provided reference image.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.

No build tools are required. Google Fonts are loaded online; a system fallback is included.
The Telegram buttons currently point to `https://t.me/`. Replace that URL in `index.html` with your actual Telegram invite link before publishing.

## Files
- `index.html` — page content
- `style.css` — responsive dark/neon styling
- `script.js` — mobile navigation toggle
- `assets/hero-reference.jpg` — hero image crop taken from the supplied reference
